# Редактор новостей — Playgama Bridge

Это HTML5-версия игры «Редактор новостей» для загрузки в Playgama. Исходник — предоставленный пользователем архив сборки Яндекс Игр. Механики игры сохранены: 26 уроков, публикация новостей, трата и восстановление энергии, серия практики, ежедневный подарок, магазин, аватары, оформление, обучение слепой печати, русский/английский языки.

## Интеграция платформы

- Вместо YaGames SDK используется **Playgama Bridge 2** (CDN: `https://bridge.playgama.com/v2/stable/playgama-bridge.js`).
- Инициализация платформы, `game_ready`, `gameplay_started`/`gameplay_stopped`, события паузы и управления звуком: `js/playgama-bridge.js`.
- Реклама: межстраничная после успешного задания с паузой не менее 60 секунд; реклама за награду для дополнительной энергии и удвоения награды. Награда выдаётся **только** по событию `rewarded` от Bridge, а не за закрытие окна. В локальном режиме на `localhost` доступна явно подтверждаемая тестовая реклама, без обращения к сети.
- Синхронизация прогресса: `js/playgama-progress.js` через `bridge.storage.get/set`, при недоступности облака работает `localStorage`.
- Рейтинг опыта `editorExperience`: `bridge.leaderboards` (если платформа поддерживает; создать рейтинг с этим ID в кабинете Playgama).
- Авторизация опциональна, без аккаунта игра работает.
- В `playgama-bridge-config.json` задана платформа и ID рейтинга.
- Код и тексты не содержат нативных вызовов Яндекс SDK.

## Графика и оптимизация

Сохранены все 36 изображений (иконки, аватары, фоны, руки, скины), но оригинальные PNG конвертированы в высококачественный WebP для ускорения браузерной загрузки. Исходный архив пользователя остаётся источником PNG. Повторяющий изображения 5,8-мегабайтный встроенный `assets/hands/local-assets.js` исключён: WebP-изображения загружаются напрямую. Музыкальный MP3 сохранён без перекодирования.

## Запуск

Открой папку на HTTP-сервере, например:

```bash
python -m http.server 8000
```

Затем открой `http://localhost:8000`. Отсутствие Bridge в локальном режиме не мешает запуску. Проверка SDK при работающей платформе выполняется в **Playgama QA Tool**, поскольку при локальном запуске используется автономный режим.

Программные проверки:

```bash
node tests/bridge.test.cjs
find js data -name '*.js' -exec node --check {} \;
```

## Публикация

1. Создать игру в `https://developer.playgama.com/` и заполнить карточку.
2. Выгрузить содержимое этой папки в ZIP (корневой `index.html`) или использовать готовый архив.
3. Загрузить ZIP в Playgama и запустить QA Tool.
4. Проверить на площадке: загрузку, обе локализации, звук, энергетику, сохранения, показ межстраничной рекламы, награду только после `rewarded`, рейтинг и авторизацию (если поддерживается).
5. Создать лидерборд с ID `editorExperience`, если хочешь публиковать общий опыт.
6. Обновления Яндекс-версии сохранять отдельно: этот билд с ней больше не связан.

**Важно:** Сохранения из личного хранилища Яндекс Игр не мигрируют автоматически в Playgama — у площадок разные профили. При первом запуске на Playgama пользователи начинают с нового профиля, если их прогресс не был вручную перенесён.
