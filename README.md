# Редактор новостей — Playgama Bridge 2

HTML5-игра «Редактор новостей», перенос из сборки Яндекс Игр на **Playgama Bridge 2**.

## Состояние репозитория

Исходная игра уже адаптирована и протестирована в отдельном готовом архиве. Чтобы все графические и аудиофайлы оказались **в GitHub**, загрузи сюда один архив с точным именем `source-build.zip` (менее 9 МБ) через **Add file → Upload files**. GitHub Actions автоматически:

1. Распакует его в корень репозитория;
2. Проверит наличие `index.html`, Bridge SDK и игровых ассетов;
3. Выполнит Node.js-тесты платформенной интеграции и проверку синтаксиса;
4. Добавит и закоммитит все файлы игры в `main`;
5. Удалит промежуточный ZIP из репозитория.

После успешного запуска «Import Playgama game archive» здесь будут все исходники и ассеты — с ними сможет работать Codex.

**Не загружай исходный архив из Яндекс Игр:** `source-build.zip` должен быть адаптированной сборкой, подготовленной для Playgama.

## Что уже интегрировано в адаптированной сборке

- Официальный Playgama Bridge v2 CDN и `playgama-bridge-config.json`;
- Межстраничная и наградная реклама, награда **только после подтверждения события** `rewarded`;
- Cloud Save через `bridge.storage` с резервным сохранением в браузере;
- Рейтинг `editorExperience` и необязательная авторизация (при поддержке площадки);
- Сигналы загрузки, старта и паузы; переключение языка по настройке платформы;
- 36 изображений WebP вместо тяжёлых PNG; музыка остаётся оригинальным MP3.

Локальный запуск: `python -m http.server 8000` из корня проекта. Для Playgama загрузи ZIP с `index.html` в корне, проверь сохранение и рекламу через QA Tool.

*Пользовательский прогресс с Яндекс Игр автоматически не переходит на Playgama.*
